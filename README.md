# Поиск и Снабжение — сайт заявок

Квиз-сайт службы комплексного снабжения «Поиск и Снабжение» (г. Якутск).
Клиент заполняет заявку за 6 шагов, заявка уходит в Google Таблицу и в Telegram владельца.

- `index.html` — весь сайт одним файлом: вёрстка, иконки, логика квиза.
- `og.png` — картинка 1200×630 для превью ссылки в WhatsApp и Telegram.

## Как это работает

Сайт отправляет заявку на Google Apps Script (адрес в поле `endpoint` объекта `CONFIG` в начале скрипта в `index.html`).
Скрипт записывает строку в Google Таблицу «Поиск и Снабжение — заявки» и шлёт сообщение с фото в Telegram-бот @PoiskSnab14_bot.
Токены и chat_id хранятся только в настройках скрипта, в этом репозитории их нет.

## Как что-то поменять

- Телефон, адрес сервера, лимиты файлов: объект `CONFIG` в начале `<script>` в `index.html`.
- Тексты и категории: прямо в HTML, они на русском и подписаны комментариями по шагам.
- Реквизиты ИП и политика: подвал страницы и блок `policyOverlay`.

После правки файла в ветке `main` GitHub Pages обновляет сайт примерно за минуту.
Править можно прямо на сайте GitHub: открыть `index.html`, нажать карандаш, сохранить.
